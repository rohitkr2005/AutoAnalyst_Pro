Security & Compliance

Enterprise-Grade Zero-Trust Architecture

Designed to satisfy stringent corporate infosec requirements with zero data leakage and cryptographic session isolation.

Session Vault & Argon2

Enterprise credentials secured with Argon2/bcrypt hashing, secure HTTP-only session cookies, and time-bound 6-digit OTP email verification.

OWASP Top 10 Fortified

Hardened with strict Content Security Policy (CSP), anti-clickjacking frame protection, nosniff MIME validation, and sliding-window rate limiters.

Zero Cloud Retention

Uploaded datasets and relational models are processed strictly in ephemeral session memory. Raw payloads are never indexed or saved to external storage.

Granular Workspace RLS

Row-Level Security (RLS) enforcement ensures users only access their own analysis logs and private datasets across Supabase and local SQLite instances.

// Sample DAX Evaluation Pipeline
DEFINE MEASURE 'Orders'[Gross Profit Margin] =
  DIVIDE(
    SUM('Orders'[Revenue]) - SUM('Orders'[COGS]),
    SUM('Orders'[Revenue]),
    0.0
  )

// Output: Evaluated in < 12ms against 500k rows
EVALUATE ROW("Margin", [Gross Profit Margin])
